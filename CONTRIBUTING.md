# Contributing

1. Siga a convenção de apps Django por domínio (padrão Radar Brasil) — detalhes em `CLAUDE.md`, seção "Diretrizes de Engenharia".
2. Desenvolvimento em `next` (remoto `origin`); `main` (remoto `production`) só recebe promoção explícita.
3. Rode `pytest` antes de enviar — a suíte tem que continuar verde.
4. Respeite o piso de qualidade em `CONSTRAINTS.md`.
